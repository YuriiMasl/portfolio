# Портфолио Юрия

Статическая русскоязычная страница разработчика сайтов для малого бизнеса. Без сборки, без API, без npm-зависимостей в рантайме. Хостинг — GitHub Pages: https://yuriimasl.github.io/portfolio/

## Что на странице

- Первый экран: заголовок, лид, два действия и стойка с тремя экранами демо-кейса и стеклянной альстромерией.
- Кейс «Люблю, целую»: сравнение «было / стало» ползунком, список сделанного, честная оговорка о стадии работы.
- Процесс работы: разбор задачи, форма, сборка, отжиг.
- Услуги, портрет, контакты (Telegram @IOpaWho, ВКонтакте, телефон).

Отзывов, цен, логотипов клиентов и метрик на странице нет намеренно: их не существует. Портфолио показывает один демонстрационный макет, а не выдаёт его за запущенный клиентский сайт.

## Файлы

- `index.html` — разметка и весь текст.
- `workshop.css` — оформление: палитра, типографика, сетка, компоненты, адаптив.
- `workshop.js` — ползунок сравнения и движение (GSAP, прогрессивное улучшение).
- `assets/` — скриншоты кейса, портрет, иллюстрация альстромерии, шрифты в `assets/fonts/`.
- `vendor/gsap.min.js`, `vendor/ScrollTrigger.min.js` — локальные GSAP 3.13, лицензия: https://gsap.com/standard-license
- `PRODUCT.md` — правда продукта: аудитория, позиционирование, ограничения.
- `DESIGN.md` — визуальная система: палитра, шкала шрифтов, компоненты, движение, правила.
- `.impeccable/` — рабочие артефакты Impeccable: бриф поверхности, конфиг, токены, скриншоты проверки.
- `_legacy/` — предыдущая версия страницы и её проверочные скрипты, сохранены для истории.

## Локальный запуск

Из корня репозитория:

```text
py -m http.server 0 --bind 127.0.0.1
```

Порт появится в строке `Serving HTTP ... port N`, страница — по адресу `http://127.0.0.1:N/`. Остановка — Ctrl+C. Двойной клик по `index.html` не заменяет проверку по HTTP: шрифты и относительные пути ведут себя иначе.

## Деплой

Пуш в ветку `main` — GitHub Pages пересобирает страницу автоматически (source: `main`, `/`). Проверка через `gh api repos/<owner>/portfolio/pages`.

## Проверено

- Скриншоты 1440×900 и 390×844, полная прокрутка, консоль без ошибок.
- Детектор Impeccable: замечания только по `clamp()` в отступах (детектор не вычисляет `clamp`, ложное срабатывание) и по мгновенному отсвету панели на загрузке (намеренный эффект «стекло остывает»).
- Читаемость без JavaScript: текст, панели и сравнение (сдвиг недоступен, обе картинки видны) остаются на месте.
