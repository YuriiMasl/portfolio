# Портфолио Юрия

Статическая русскоязычная страница разработчика сайтов для бизнеса в Воронеже. Без сборки, API и новых npm-зависимостей. Кинематографичная прокрутка использует локальные GSAP и ScrollTrigger; это прогрессивное улучшение, а не условие доступа к содержимому.

## Локальный запуск

Из **корня проекта**, а не из папки `portfolio`, выполните на Windows:

```text
py -m http.server 0 --bind 127.0.0.1
```

ОС выберет свободный порт. Возьмите номер из строки `Serving HTTP … port N` и откройте `http://127.0.0.1:N/portfolio/`, заменив `N` фактическим номером. Не используйте порт `0` в адресе браузера. Порт 8000 ранее был недоступен (`WinError 10013`), поэтому фиксированный порт не требуется. Остановка сервера — Ctrl+C. Если Python доступен только как `skpy`, замените `py` на `skpy`.

Двойной клик по HTML не заменяет проверку маршрута `/portfolio/` по HTTP. Node и npm для запуска не нужны.

## Файлы и контракт интеграции

- `index.html` — семантическая разметка и статическое содержимое, включая запасной путь без JavaScript.
- `cinematic.css` — оформление сцен и адаптивность; подключается после остальных стилей.
- `projects.js` — подтверждённые данные (`window.PORTFOLIO_DATA`), прежний формат сохраняется.
- `portfolio.js` — безопасное отображение данных и интерфейс; после наполнения отправляет `portfolio:ready` на `document`.
- `cinematic.js` — только GSAP-анимация; инициализация на `DOMContentLoaded`, обновление ScrollTrigger на `portfolio:ready` без повторного создания анимаций.
- `vendor/gsap.min.js`, `vendor/ScrollTrigger.min.js` — локальные библиотеки версии 3.13.0, побайтные копии из `site_lyublyu/vendor/`. Исходные лицензионные заголовки сохранены; условия: https://gsap.com/standard-license. CDN, Lenis и установка пакетов не нужны.
- `vendor/sync_vendor.py` — служебное копирование и проверка идентичности локальных библиотек; не используется страницей. Запуск: `py portfolio/vendor/sync_vendor.py`. При отличающейся существующей копии завершится с ошибкой без перезаписи.
- `assets/` — изображения существующей работы.
- `w2K7lKvhrwA.jpg` — предоставленная фотография Юрия (`img.profile-photo`); оригинал не изменяется.

Порядок `defer`-скриптов: `projects.js`, `portfolio.js`, `vendor/gsap.min.js`, `vendor/ScrollTrigger.min.js`, `cinematic.js`. Якоря: `#hero`, `#services`, `#cases`, `#about`, `#contact`; контейнер работ — `#case-list`.

Целевой контракт: обычный CSS не скрывает содержимое; без JS или библиотек доступны текст, фото и ссылка демо. Прокрутка нативная, без перехвата колеса. Ниже 768px сцены не закрепляются. При `prefers-reduced-motion: reduce` нет закрепления, параллакса и scroll-scrub. Эти условия требуют итоговой проверки интегрированных файлов и браузера; само описание не является подтверждением приёмки.

## Как добавить работу

Добавьте объект в массив `projects` файла `projects.js`:

```js
{
  title: "Название работы",
  category: "Тип бизнеса · стадия работы",
  description: "Что сделано и что подтверждено по факту",
  image: "assets/project-hero.webp",
  imageAlt: "Описание изображения",
  href: "https://example.com/",
  linkLabel: "Посмотреть работу"
}
```

Все поля — строки, пути считаются относительно `index.html`. Пустой `href` означает отсутствие ссылки. Без заголовка карточка не выводится; текст не должен интерпретироваться как HTML. Обновляйте также статическую карточку в `index.html`, чтобы новый кейс оставался доступен без JS.

В `contact` укажите только подтверждённые `label` и `href` (HTTP, HTTPS, mailto или tel). Сейчас оба поля пусты, страница должна честно сообщать «Контакт пока не опубликован». Формы отправки обращений, серверной обработки и подтверждённого способа связи нет.

## Реальный материал кейса

«Люблю, целую», цветочный салон, Воронеж — аудит и демонстрационный макет, **не запущенный клиентский сайт**. Демо: https://yuriimasl.github.io/lyublyu-demo/. Не приписывать кейсу неподтверждённые результаты, клиентов или показатели. Открытие внешнего демо требует сети; собственные библиотеки и изображения портфолио локальные.

## Проверки и ограничения приёмки

Из корня проекта:

```text
py portfolio/check_portfolio.py
py portfolio/qa_cinematic/check_contract.py
```

Первая команда — существующая структурная регрессия; она не доказывает правильность данных или рендера. Вторая — дополнительная статическая проверка cinematic-контракта после передачи QA. Ни одна не заменяет визуальную приёмку и исполнение JavaScript в браузере.

Перед публикацией в подключённом **Chrome**, не Edge, проверить:

1. `/portfolio/` на ширинах 1440 и 390px: все пять сцен, читаемость, отсутствие горизонтальной прокрутки и перекрытых кнопок.
2. Загрузку обоих локальных скриптов, фото и изображений кейса; отсутствие ошибок Console/Network.
3. Tab/Shift+Tab, видимый фокус, все якоря и ссылку реального демо; прямой вход по якорю.
4. Прокрутку вперёд/назад, смену ширины через 768px, повторное `portfolio:ready`: отсутствие дублирующихся закреплений и скачков высоты.
5. Reduced-motion до загрузки и при переключении: всё читается, нет pin/parallax/scrub.
6. Заблокировать загрузку библиотек и перезагрузить: содержимое и демо доступны. Отдельно отключить JavaScript и перезагрузить: кейс, фото и основные ссылки остаются доступны, нет вечной «Загрузки работ».

На момент подготовки этого README проверена только идентичность копий библиотек локальным исходникам. Интеграционные проверки, HTTP-загрузка и визуальная приёмка cinematic-версии здесь не заявляются выполненными.

## Публикация

Для сохранения маршрута `/portfolio/` разместите папку `portfolio` в корне статического хостинга. Нужны `index.html`, `cinematic.css`, `projects.js`, `portfolio.js`, `cinematic.js`, `w2K7lKvhrwA.jpg`, `assets/` и два JS-файла `vendor/`. Служебные Python-скрипты, отчёты QA и внутренние документы публиковать не требуется. Не загружайте только HTML без связанных ресурсов.

Публичный адрес портфолио пока не подтверждён. Локальный запуск ничего не публикует; развёртывание и настройка GitHub Pages — отдельные действия.
