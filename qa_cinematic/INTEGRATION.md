# Интеграция cinematic-портфолио

## Изменения интегратора
- Снят overflow-x: clip с общей настольной сцены: он блокировал pinCandidate. Корневое горизонтальное ограничение и мобильный clip сохранены.
- Перед закреплением снимается и ожидающий reveal (не только уже проигрываемый): иначе opacity: 0 могло остаться на кейсе.
- Откат tween выполняется в обратном порядке, чтобы поздний tween не восстанавливал transform более раннего gsap.set после очистки режима.
- JS-картинка кейса получила data-parallax. Геометрия пина и движение изображения имеют разных владельцев.
- Вместо вечного загрузочного текста добавлена полноценная статическая карточка с изображением и ссылкой. JS заменяет её данными projects.js, формат данных не менялся.

- Первый HTTP smoke-check обнаружил MIME application/octet-stream для WebP в Windows http.server. Это ограничение MIME-таблицы локального сервера, не доказательство дефекта изображения. Проверка дополнена проверкой сигнатуры RIFF/WEBP и явным WARN; JPEG/CSS/JS по-прежнему проверяются по MIME.

## Статус приёмки
- PASS статически: все пять сцен и якорей, один портрет, кейс и локальные библиотеки, правильный defer-порядок, видимый CSS fallback, ссылка на демо без JS, честный неопубликованный контакт.
- WARN: portfolio:ready отправляется до cinematic.js. Первичная сборка намеренно идёт на DOMContentLoaded и вызывает refresh; событие предназначено также для последующего обновления.
- НЕ ПРОВЕРЕНО в браузере: фактическое исполнение GSAP, работа pin/scrub, 1440/390px, отсутствие горизонтальной прокрутки и перекрытий, якорные переходы, клавиатура, пропорции портрета, reverse-scroll, resize и повторный portfolio:ready, reduced-motion, отключённые библиотеки и JavaScript, внешний демо-сайт.
- Причина: chrome_open для локального адреса вернул `Local and home-network addresses are not opened by the agent.` Ограничение не обходилось; Edge/отдельный браузер не запускался согласно предпочтению владельца.

TASK.md, существующие тесты и приёмочные фикстуры не изменены. Публикация в интернете не выполнялась. Статические проверки не заменяют визуальную приёмку.
